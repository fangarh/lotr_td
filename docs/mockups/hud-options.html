Shadow Conquest HUD options

Три направления для следующего HUD-шагa. Все варианты показаны как overlay над одним и тем же spike-полем; это дизайн-макет, не production Godot UI.

1. Mobile-safe read-only bar recommended

StateRunning
Wave1 / 1
Lives5
Breaches0
Enemies3

Узкий read-only foundation: ближе к будущему mobile HUD, но без кнопок и gameplay ownership.

2. Debug panel + Next Wave progression hook

State: wave_clear Wave: wave-1 (1/2) Lives: 4 Breaches: 1 Active enemies: 0 [ Next wave ]

Быстро даёт touch-кнопку, но сразу связывает HUD с progression. Лучше после read-only layout.
